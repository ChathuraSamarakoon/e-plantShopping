# Paradise Nursery 🌿

A React shopping cart application for an online houseplant store, built with Vite, React Router, and Redux Toolkit.

## Project Name: Paradise Nursery Shopping Application

## Features

- **Landing Page** — Beautiful background image, company description, and "Shop Plants" CTA
- **Product Listing Page** — 18 unique houseplants across 3 categories with thumbnail, name, price, and Add to Cart
- **Shopping Cart Page** — Full cart management with quantity controls, item removal, and total cost display
- **Redux State Management** — Global cart state via `@reduxjs/toolkit`
- **Responsive Design** — Mobile-friendly layout

## Tech Stack

- React 18
- Vite
- React Router v6
- Redux Toolkit + React Redux
- CSS Custom Properties

## Pages

| Page | Route | Description |
|------|-------|-------------|
| Landing | `/` | Company intro with Get Started button |
| Products | `/plants` | Browse all houseplants by category |
| Cart | `/cart` | View and manage cart items |

## Plant Categories

1. 🌴 **Tropical Foliage** — Monstera, Bird of Paradise, Philodendron, and more
2. 🌵 **Succulents & Cacti** — Echeveria, Jade Plant, Aloe Vera, and more
3. ✨ **Air-Purifying Plants** — Snake Plant, Peace Lily, Pothos, and more
